# Squeektoshi game 🐹

Telegram mini-app для экосистемы [Squeekchain](https://squeekchain.com): игроки крутят своё колесо вместе с настоящим хомяком Squeektoshi.

- **Хомяк бежит** → его живые обороты бустят каждый спин игроков (×1 … ×7, `1 + rpm/20`).
- **Хомяк спит** → ночная смена: люди крутят колесо сами, но **1000 человеческих спинов = 1 хомячий оборот**.
- Каждый день счёт **«люди vs хомяк»**, лидерборд за день и за всё время, кнопки «поделиться» в Telegram и X.
- Рефералка: личная ссылка `t.me/<бот>?start=r<id>`; пригласивший получает +10% от всех очков друга (очки идут только с реальных спинов с тем же лимитом скорости, так что пустые акки ничего не дают).
- Будильник (по желанию игрока): бот пишет в личку, когда Squeektoshi начинает бегать, не чаще раза в 3 часа. Включается кнопкой в `/start`, командой `/alerts` или переключателем в аппе.
- Личная карточка 1200×675: аватар и ник из Telegram, спины, очки, место, счёт «люди vs хомяк». Кнопка «Get my card» — бот присылает картинку в личку.
- Кошелёк: игрок оставляет EVM-адрес в аппе или командой `/wallet 0x...`. Проверка формата и EIP-55 чексуммы (опечатку в регистре ловит), один кошелёк на одного игрока. В аппе написано прямо: награды не обещаны.
- Выгрузка для команды: админ пишет боту `/export [all|week|today] [N]` и получает CSV топа с кошельками и подсказками для ревью (см. ниже).
- Бот: `/start` (картинка + кнопки «Spin», «Invite friends», «Top», «Ping me»), `/top`, `/hamster`, `/invite`, `/alerts`, `/wallet`; по желанию алерты «проснулся / уснул» в канал и утренний итог дня.

Данные о хомяке берутся из публичного фида `https://api.squeekchain.com/v1/status` (статус колеса ACTIVE/IDLE, rpm, счётчик работы). Реальные блоки и SQK игра не минтит: это игра поверх их данных, а не часть протокола.

Community-built. Not affiliated with Squeekchain.

## Как устроено

Один Cloudflare Worker отдаёт и мини-апп, и API (один адрес `https://squeektoshi.<поддомен>.workers.dev`), данные в D1.

```
web/index.html      мини-апп (один файл): колесо на canvas, статус хомяка, счёт, лидерборд
worker/
  wrangler.jsonc    конфиг воркера (мини-апп раздаётся как static assets из ../web)
  src/index.ts      роуты API, бот, cron, авто-настройка бота
  src/game.ts       правила: анти-чит, буст, детектор "проснулся/уснул" (чистые функции)
  src/hamster.ts    чтение и нормализация /v1/status, кэш 10 с, фолбэк
  src/migrate.ts    миграции базы, применяются воркером сами
  src/telegram.ts   проверка подписи Telegram initData, отправка сообщений
  src/wallet.ts     проверка EVM-адреса (EIP-55), CSV-выгрузка топа с флагами
  schema.sql        таблицы D1
  test/             юнит-тесты (vitest) + интеграционный прогон против локального worker
```

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/` | мини-апп |
| GET | `/api/state` | статус хомяка, текущий буст, счёт «люди vs хомяк» за сегодня |
| POST | `/api/spin` | `{revs, seq}` + заголовок `X-Init-Data` → засчитанные обороты, мои очки |
| GET | `/api/me` | мой день, итоги, друзья, моя инвайт-ссылка, статус будильника |
| POST | `/api/notify` | `{on}` — включить/выключить будильник |
| GET | `/api/avatar` | моё фото из Telegram (через воркер: ссылки на файлы содержат токен) |
| POST | `/api/card` | PNG моей карточки → бот присылает её мне в личку |
| POST | `/api/wallet` | `{address}` (или `null`, чтобы удалить) → сохранённый кошелёк |
| GET | `/api/leaderboard?scope=today\|all` | топ-20 + моё место |
| POST | `/tg/webhook` | апдейты бота |

**Анти-чит.** Каждый батч проверяется подписью Telegram (`initData`, HMAC от токена бота). Сервер засчитывает не больше 6 оборотов в секунду с момента прошлого батча (максимум за 15 с), так что скриптом быстрее «физического» колеса не накрутить. Повтор батча с тем же `seq` отбивается.

**Бережно к их API.** Игроки в API Squeekchain не ходят, ходит только воркер: статус кэшируется на 10 с, плюс cron раз в минуту.

**Бот настраивает себя сам.** При первом открытии приложения по его настоящему адресу воркер ставит вебхук (с секретом), кнопку меню «Spin», список команд и описание «community, not affiliated». Токен никуда руками вставлять не нужно, кроме `wrangler secret put`.

## Деплой (бесплатно, ~10 минут)

Нужно: Node 20+ и git на компе, аккаунт Cloudflare, бот от [@BotFather](https://t.me/BotFather).

В PowerShell, по одной команде. На вопросы отвечай `y`:

```powershell
cd $HOME\Documents
git clone https://github.com/senq1337/squeektoshigame
cd squeektoshigame\worker
npm install
npx wrangler login
npx wrangler d1 create squeektoshi --binding DB --update-config
npx wrangler deploy
npx wrangler secret put BOT_TOKEN
node -e "console.log(require('crypto').randomBytes(24).toString('hex'))" | npx wrangler secret put WEBHOOK_SECRET
```

- `wrangler login` открывает браузер: войди в нужный аккаунт Cloudflare и нажми Allow.
- `d1 create ... --update-config` сам допишет базу в `wrangler.jsonc`. Таблицы воркер создаёт и обновляет сам (src/migrate.ts).
- Первый `wrangler deploy` попросит выбрать поддомен `*.workers.dev` и в конце напечатает адрес приложения.
- `secret put BOT_TOKEN` спросит значение: вставь токен из BotFather. Токен не попадает ни в файлы, ни в git.
- Последняя команда сама генерирует случайный секрет вебхука.

Потом **открой адрес приложения в браузере один раз** (`https://squeektoshi.<поддомен>.workers.dev`). В течение минуты бот настроит себя. Дальше в Telegram: бот → `/start` → кнопка Spin.

Аватар и картинка до старта (через API боту их не поставить, только руками):
- BotFather → `/mybots` → бот → Edit Bot → Edit Botpic → `art/avatar.png`.
- BotFather → `/mybots` → бот → Edit Bot → Edit Description Picture → `art/welcome_640x360.png`.

По желанию:
- **Алерты и итог дня:** создай канал, добавь бота админом, впиши id канала (`-100...`) в `ALERT_CHAT_ID` в `wrangler.jsonc`, `npx wrangler deploy`.
- **Ссылка вида `t.me/<бот>/<app>`:** `/newapp` в BotFather, впиши в `APP_LINK`.

Обновить после изменений в репо (в папке `worker`): `git pull`, `npm install`, `npx wrangler deploy`.

**Выгрузка топа (админ).**
1. Напиши боту `/myid`, он ответит твоим Telegram id.
2. `npx wrangler secret put ADMIN_IDS`: вставь id (несколько через запятую). Редеплой не нужен.
3. `/export` (всё время, топ-100), `/export week 50`, `/export today`. Бот пришлёт CSV.

Колонки: место, tg id, username, очки и спины за период, кошелёк, когда его поставили, кто пригласил, сколько пригласил, бонус с рефов, дней в игре, первый заход, флаги. Флаги — подсказки, ничего не вырезается автоматически:
- `operator` — админ бота (билдер). Виден в списке, чтобы никто не сказал, что его спрятали.
- `no_wallet` — нет кошелька.
- `ref_heavy` — больше половины очков с рефов (типичная форма фермы альтов).
- `inviter_in_top` — пригласивший тоже в этом списке.
- `wallet_recent` — кошелёк поставлен или сменён меньше суток назад.
- `one_day` — играл только один день.

## Лимиты бесплатного тарифа

- Workers: 100k запросов в сутки. Активный игрок шлёт батч раз в 5 с и опрашивает статус раз в 10 с: около 1k запросов в час.
- Будильник шлёт до 40 пингов за запуск крона (раз в минуту): лимит бесплатного тарифа — 50 исходящих запросов на запуск. На $5-тарифе можно поднять.
- D1: 100k записанных строк в сутки — самый узкий лимит. Батч пишет ~5 строк, то есть примерно **25–30 игроко-часов в сутки** бесплатно.
- Если игра залетит: Workers Paid за $5/мес снимает оба лимита с огромным запасом.

## Локальная проверка

Нужен локальный конфиг с базой (в git не попадает):

```bash
cd worker
cp wrangler.jsonc wrangler.local.jsonc   # и добавь в него:
#   "d1_databases": [{ "binding": "DB", "database_name": "squeektoshi", "database_id": "local-test-0001" }]
printf 'BOT_TOKEN=123456:TEST_TOKEN_not_real\nWEBHOOK_SECRET=testsecret\n' > .dev.vars
npx wrangler d1 execute squeektoshi -c wrangler.local.jsonc --local --file=schema.sql
npm test
npx wrangler dev -c wrangler.local.jsonc --local --test-scheduled --var DEV_ALLOW_UNSIGNED:1 --var ADMIN_IDS:7
# интеграционный прогон: мок-фид на :8799 и --var STATUS_URL:http://127.0.0.1:8799/v1/status, затем
#   node test/integration.mjs http://127.0.0.1:8787 http://127.0.0.1:8799
# мини-апп без Telegram: http://127.0.0.1:8787/?dev=1&user=5
```

Демо без бэкенда (хомяк 25 с бежит, 25 с спит, фейковый лидерборд): `web/index.html?demo=1`.

`DEV_ALLOW_UNSIGNED=1` разрешает запросы без подписи Telegram. **В продакшене он `"0"`** (так стоит в `wrangler.jsonc`).
